# Заполнение Google Sheets

Эти CSV — готовые данные, перенесённые со старого сайта (nematovs700.github.io/Umra), в формате схемы нового сайта. Файлы носят подготовительный характер (не публикуются на сайте), их нужно один раз занести в таблицу.

Таблица: https://docs.google.com/spreadsheets/d/1A22dRlytShWd24nxfnkGFbDmxjh_8bWZWVPfBy7buuk/edit

## Как импортировать

Для каждого файла — создать вкладку с точно таким же названием (`Tariffs`, `TariffHotels`, `Media`, `FAQ`, `Contacts`), затем:

1. Открыть вкладку → File → Import → Upload → выбрать соответствующий `.csv`.
2. Import location: **Replace current sheet**.
3. Separator type: **Comma**.
4. Нажать Import data.

Либо просто открыть CSV в текстовом редакторе и вставить содержимое (Google Sheets сам разберёт запятые при вставке как "Paste special → Values only", хотя Import — надёжнее для текста с запятыми внутри кавычек).

- **Media.csv** — это ожидаемые имена файлов, самих видео/фото ещё нет ни в одном GitHub Release — см. `README.md` в корне проекта, раздел "Как добавить/заменить фото или видео". Пока файлы не загружены, в галерее тарифа будут "битые" превью — это ожидаемо до загрузки реальных медиа.
- **FAQ и Contacts** — перенесены со старого сайта как есть (переводы UZ/TJ — рабочий вариант, стоит вычитать носителем языка перед публикацией, особенно таджикский).
